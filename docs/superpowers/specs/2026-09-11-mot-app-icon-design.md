## 2. SVG 设计规格（精确坐标 v2）

viewBox: `0 0 1024 1024`

### 2.1 背景
```xml
<rect x="0" y="0" width="1024" height="1024" rx="180" ry="180" fill="#0A0A0A"/>
```

### 2.2 O 字母（中央主体，最大、最厚、发光）

- **核心实心圆环**：外径 388，内径 220，环壁厚 168（"厚实饱满"）
  - `cx=512 cy=512`
  - 填充 `#00FF41`，`stroke="none"`（实心，不是描边圆环）
  - 几何实现：用 `fill-rule="evenodd"` 的 path，外圆 + 内孔路径形成镂空
- **垂直范围**：y ∈ [62, 962] → 高度 900，几乎撑满上下边距（margin ≈ 62）
- **水平范围**：x ∈ [124, 900] → 宽度 776（远超 M 和 T）
- **内孔紧凑**：内径 220，内孔面积 = π × 110² ≈ 38013 px²，环面积 = π × (194² - 110²) ≈ 80257 px²，环:孔比 ≈ 2.1:1（"镂空面积极小"）

### 2.3 O 发光（静态多环，无 filter）

在 O 主体**外侧**画 3 个同心透明环，模拟发光衰减：
- 环 1（最外、最暗）：外径 470，alpha 0.08，`fill="#00FF41"`
- 环 2（中间）：外径 432，alpha 0.15，`fill="#00FF41"`
- 环 3（最内、最亮）：外径 408，alpha 0.25，`fill="#00FF41"`
- 渲染顺序：发光环（外→内）→ O 主体（最上层）

实现方式：每个发光环都是 `fill-rule="evenodd"` 的圆环 path，alpha 从外到内递增，模拟 gaussian blur 的中心衰减。

### 2.4 M 字母（左侧白色小字）

- 高度约为 O 的一半 ≈ 450 px，垂直中心线 y=512
- y ∈ [287, 737]
- 白色 `#FFFFFF`，无发光
- 几何 M：左 V + 右 V，共 4 段折线
- 水平区域：x ∈ [40, 200]，宽 160

### 2.5 T 字母（右侧白色小字，与 M 镜像）

- 同 M 高度 450
- y ∈ [287, 737]
- 白色 `#FFFFFF`，无发光
- 几何 T：顶部横杠 + 中央竖杠
- 水平区域：x ∈ [824, 984]，宽 160

### 2.6 间距与对齐

- **M 右边缘 (x=200) 与 O 左边缘 (x=124)**：等等，O 包含发光；O 主体左边缘 x=124
- **修正**：M 右边缘 x=200 → O 左边缘 x=124，**重叠 76px** ❌
- **真正规则**：M 的右边缘距 O 主体左边缘 **84 px**；T 的左边缘距 O 主体右边缘 **84 px**
- **修正后坐标**：
  - M 区域：x ∈ [-44, 116]？不行，超出画布
  - 重新规划：O 主体向左收缩 100 px → x ∈ [224, 800]
  - M 区域：x ∈ [80, 224]，宽 144；M 右边缘 (x=224) 与 O 左边缘 (x=224) **相切**，无间距 ❌
  - 调整：O 主体外径 312（从 388 缩 76），x ∈ [200, 824]
  - M 区域：x ∈ [40, 184]，宽 144；M 右边缘 (184) 与 O 左边缘 (200) 间距 **16** ❌
- **重做几何（采用以下数值）**：
  - O 主体外径 **320**，内径 180，环壁厚 140（保持"厚实"）
  - O 主体范围：x ∈ [192, 832]，y ∈ [192, 832]，高度 640（占图标 ~62%）
  - O 发光最外环外径 384（向外扩展 32px）
  - M 区域：x ∈ [64, 192]，宽 128；M 右边缘 (192) 与 O 左边缘 (192) 相切 → 实际间距 0
  - **为了满足"严格间距"要求**：
    - O 主体外径 296，内径 168，环壁厚 128
    - O 主体范围：x ∈ [208, 816]，y ∈ [208, 816]
    - O 发光最外环外径 360
    - M 区域：x ∈ [80, 200]，宽 120；M 右边缘 (200) 与 O 左边缘 (208) 间距 **8**（视觉足够）
    - T 区域：x ∈ [824, 944]，宽 120；T 左边缘 (824) 与 O 右边缘 (816) 间距 **8**
- **最终采用**：
  - O 主体：cx=512 cy=512, 外径 r=304, 内径 r=176 (环壁 128), fill #00FF41, fill-rule="evenodd"
  - O 发光（外→内）3 环：
    - r=368, alpha=0.06
    - r=344, alpha=0.12
    - r=320, alpha=0.22
  - M 区域：x ∈ [80, 208]，宽 128，y ∈ [288, 736]，高 448（≈ O 高度的 0.7）
  - T 区域：x ∈ [816, 944]，宽 128，y ∈ [288, 736]，高 448
  - **M 右边缘 (208) = O 左边缘 (208) → 实际间距 0（相切）**
  - 为了真正满足"M 的右边缘与 O 的左边缘间距等于 T 的左边缘与 O 的右边缘间距"且有可见间距：
    - 改为 M 区域 x ∈ [56, 184]，T 区域 x ∈ [840, 968]，间距 24px

## 3. 字体策略（依然用 path）

保持 build.rs 不依赖外部字体：
- M 和 T 全部用 `<path>` 几何绘制
- O 用 `<path>` 的 `fill-rule="evenodd"` 实现空心圆环（外圆 + 内圆两段 arc）
- 发光环也用 `<path>` 的 `fill-rule="evenodd"`（外圆 + 内孔）填充低 alpha 绿色

---

## 4. 复用 build.rs 流水线

无需修改 `build.rs`：
- 仍是单一 SVG 源 `assets/icon.svg`
- build.rs 自动读取并栅格化 9 个尺寸
- PNG/ICO/ICNS 全部产物自动更新

只需要替换 `assets/icon.svg` 内容并 `cargo build` 即可。

## 5. 设计验证清单

- [ ] SVG 视觉：黑色背景，绿色 O 居中最大、白色 M/T 在两侧小字
- [ ] O 主体高度 ≈ 600 px（占图标 ~59%），明显大于 M/T
- [ ] O 外发光可见但不刺眼（3 环 alpha 0.06 / 0.12 / 0.22 衰减）
- [ ] M/T 严格水平居中（y 中心 = 512 = O 中心）
- [ ] M 右边缘 ↔ O 左边缘间距 == T 左边缘 ↔ O 右边缘间距（= 28px）
- [ ] 无 `<filter>`、`<feGaussianBlur>`、`<feDropShadow>` 等 SVG 滤镜
- [ ] build.rs 渲染无 filter 报错
- [ ] PNG/ICO/ICNS 三个产物全部更新（mtime 新于 `assets/icon.svg` mtime）
- [ ] macOS 图标规范：中心对称、大量留白、扁平
